## Manipulator Control 


Control software for a manipulator with **6 degrees of freedom**,
built for the Sirius II rover of the SKA Robotics scientific association.

All developed in ROS 1 Noetic. 

Documentation in Polish:
- [The cool one made by Tomasz Żebrowski](docs/manip-schemat.pdf)
- [The serious one made by Klaudia Niedziałkowska ](docs/Dokumentacja_manip.pdf) (made in SysML)

*These are mainly diagrams, so even non-Polish speakers can understand them. English version in progress.*
