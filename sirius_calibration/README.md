# sirius_calibration package

This package contains calibration data for Oak-D W camera. Package was migrated from [package of the same name](https://github.com/SKA-Robotics/sirius_common/tree/noetic/sirius_calibration) for ROS1 Noetic.

The data describes IMU, RGB-D camera parameters and the ROS2 topics they are published on.

To get more informations see .yaml in those directories:
- [IMU](kalibr/camimu/)
- [RGBD](kalibr/multicam/)
